# AWSリージョン：料金と公開遅延の広域比較

2026-10-18。本人の追加依頼により、米国3地域から通常リージョン全体へ範囲を拡大。実機の測定や課金資源作成はせず、公式の公開単価と公開済みTCP測定だけを使った。比較調査として、実装・配備設定も変更しない。

## 結論

- 料金と日本からの待ち時間のバランスでは、今回もオレゴンを推奨候補とする。約47.96 USD/月、公開参考値は約99ms。
- 同じ構成の価格を算出できた33地域で最安はムンバイ/ハイデラバードの約46.05 USD/月。米国が一律最安という理解は今回の構成には当てはまらない。
- 現構成のVPC Linkが公式対応表に掲載される地域で最安はムンバイ。オレゴンとの差は約1.91 USD/月・年約22.93 USDで、東京AWS起点の公開測定はムンバイ約130ms、オレゴン約99ms。最安優先ならムンバイ、約2ドル差で待ちを減らすならオレゴンという選択。
- 台北は約56.06 USD/月・約34msで数値上は魅力があるが、今回必要なVPC Linkの公式対応表に未掲載。構成がそのまま成立すると確認できた候補には混ぜない。ハイデラバードも同様。
- 日本から近いことを重視し、公式対応表掲載も優先するならソウル（約58.58 USD/月・約33ms）や東京（約60.96 USD/月）を候補にできる。東京自己宛て約2msという測定を、国内一般ユーザーの値とは扱わない。

## 調査範囲

AmazonECSの公式リージョン別料金インデックスの34通常リージョンを全件対象にした。米州・欧州・アジア太平洋・中東・アフリカを含む。GovCloud、中国、European Sovereignはアカウント/パーティションが異なるため対象外。これらを含む世界全リージョン最安とは表現しない。

各地域の10サービスの料金表を確認。東京/米国3地域は同日取得データを再利用し、それ以外300サービス・リージョンの原本を追加取得。CloudPingの公開マトリクス35行から東京発の値を抽出し、価格対象34地域と照合した。

- 同型の料金を算出：33地域。
- カルガリー：今回取得したRDS料金表にPostgreSQL Single-AZ db.t4g.microのSKUを見つけられず、黙って別サイズへ置換しなかった。
- 料金算出可能かつVPC Link公式対応表に掲載：20地域。
- API Gateway全体の提供地域と、VPC Link V2という個別機能の対応表を区別した。未掲載を即「利用不能」と断定はしないが、公開情報だけで現構成対応を確認した地域として推奨しない。

## 同一条件

Node 0.5vCPU/1GiB・Go 0.25vCPU/1GiBのFargate ARM64を各1タスク、月730時間、RDS PostgreSQL通常サポートのdb.t4g.micro Single-AZとgp3 20GiB。アプリ/DB/保存は同一地域。

前回からAPI/Cloud Map呼出数、ログ取込/保存、S3保存6GiBと要求数、ECR2GiB、IPv4二つ、管理秘密値、アラーム等は固定。Spot・長期契約・期限付きクレジット不使用。30GiB外向き転送はアカウントの月100GB無料枠残量がある前提。他の無料枠は控除しない。税・為替・ドメイン更新・有料CI・更新時タスク重複・CPUバースト超過などは別。

DNSは従来の公開+非公開2ゾーンと問合せ予備、AZ通信0.10ドルと疎通通知0.05ドルは固定の予備費。同じ利用量の料金比較であり、各地域での本番負荷容量や実請求額を確定したものではない。独自ドメインなし検証だけの明細とは区別する。

新しい地域のRDS gp3のIOPS・Throughputの別単価を保存GB単価へ混ぜず、GB-MoのStorageだけを選択した。小数の丸め前に合計。4地域の前回集計と再計算結果が一致することも確認。

## 公開遅延の限界

通信速度のうち、今回はWebの要求に対する待ち時間を比較する。大量ファイルの転送能力（Mbps）・ページの読み込み完了時間とは異なる。RTTが短いほど大容量転送も必ず速いとはしない。

CloudPingの測定は各AWS地域のLambdaからAWSサービスのエンドポイントへのTCP接続時間。列From=ap-northeast-1、行To=各地域を使った。一時点の公開値で、AWS公式のSLAでも、自宅・モバイル回線からの測定でもない。日本国内の発信場所、回線、時刻、経路が変われば順位や差も変わりうる。第三者の測定元が公開する一次データとして利用し、今回自分で計測したとは扱わない。

下表の東京の約2msは測定発信元自身の地域。国内の全利用者に約2msという意味ではない。1ms程度の地域差に順位の確実性を持たせない。
