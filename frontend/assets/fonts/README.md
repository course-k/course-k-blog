# 記事OGP用フォント

Noto Sans JPの可変フォントを記事タイトルのPNG描画に使用する。ブラウザへ配信せず、OGP生成時の日本語・欧文の字形をコンテナ内で揃える。

- 配布元：[Google FontsのNoto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp)
- ファイル：NotoSansJP[wght].ttfをNotoSansJP.ttfとして保存
- 利用許諾：[SIL Open Font License 1.1](OFL.txt)

題字「course_kのブログ」はこのフォントで組み直さず、採用した画像を使う。
